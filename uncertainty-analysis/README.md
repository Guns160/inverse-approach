# 反问题误差分析

本文件夹保存误差分析的方法文档。不提供通用程序：每个反问题的算子、网格和输出量都不同，代码由具体课题实现，文档给出步骤、判据和代码示例。

## 一、两类误差

误差按**来源**分两类，不按统计/系统分。

| 类别 | 来源 | 包含 |
|---|---|---|
| 输入诱发 | 方法外部 | 凝聚量、重夸克质量、极点质量、OPE 截断（$\mu$ 固定，不计误差） |
| 方法内在 | 方法本身 | 平台参数 `M2_min`、`M2_max`、`Lambda`；正则化近似 $\alpha$ |

实验和格点分析里的统计/系统分类，依据是误差是随机的还是偏差主导的。本分类依据是误差来自方法外部还是方法内部。两者不是同一个切面，不能一一对应，也不要把两类映射成统计/系统。

## 二、误差估计的基本不等式

正则化解与真解之差满足

$$\|f_\alpha^\delta - f\| \;\le\; \delta\,\|R_\alpha\| \;+\; \|R_\alpha K f - f\|$$

- 第一项由输入误差 $\delta$ 决定，对应输入诱发误差。
- 第二项由有限正则化参数 $\alpha$ 决定，对应方法内在误差中的正则化近似部分。

这个不等式给出分类的数学依据，也给出每一项的估计方式。实际上界不一定紧，但每一项都有对应的可计算量。

## 三、前置判据

做误差分析之前，必须先满足两条：

1. **平台判据。** 三个方法参数（`M2_min`、`M2_max`、`Lambda`）各自存在稳定平台。
2. **端点判据。** 解在大 $s$ 端贴近 OPE 谱。

两条中任一条不满足，得到的解不能当作物理结果，误差分析也就失去意义。此时即使能算出数，误差也不覆盖真值。

## 四、分布分配

每个误差来源用哪种分布，由来源本身的性质决定。

| 误差来源 | 分布 | 理由 |
|---|---|---|
| $G_2$、$G_3$、$\bar m_c$、$M_{1S}$、$M_{2S}$ | 高斯（$1\sigma$） | 文献或 PDG 给出中心值和误差 |
| `M2_min`、`M2_max`、`Lambda` | 均匀（平台内） | 无唯一物理值，只有合法区间 |
| $\mu$ | 不抽样（固定） | 方案选择，不是测量 |
| OPE 截断 | 不抽样（差分） | 无分布可抽 |
| $\alpha$ | 不抽样（均值解回代） | 由正则化算子本身决定，不是测量分布 |

**这个分配与单参数/联合两种撒点模式无关。** 两种模式只是把同一批分布组织成不同的抽样方案，不改变任何一项的分布类型。

具体做法见各文件：[input-sampling.md](input-sampling.md)、[platform-parameters.md](platform-parameters.md)、[ope-truncation.md](ope-truncation.md)、[mu-scale.md](mu-scale.md)。
