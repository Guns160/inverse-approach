# 通用撒点误差分析

本 Skill 组织分析过程；附带程序只负责抽样、逐点求值和分布统计。使用前读取具体问题的代码、运行记录和参数定义。不要把某个项目的数值、误差或平台范围作为通用默认值。

## 两种方法

- **单参数撒点 `single`**：只随机改变指定的一个独立输入，其他独立输入固定在中心值。每个随机点重新求值，从输出分布提取该来源的不确定度。这不是确定性网格扫描，也不是只计算正负端点。
- **联合撒点 `joint`**：所有列入本次分析的参数按指定联合分布同时抽样，每一行输入只求值一次。从联合撒点得到的输出分布提取本次总不确定度。不要把单参数结果平方相加替代联合撒点。

一次求解可返回任意数量的观测量。同一随机输入点产生的各观测量保持配对，不能分别抽样后拼接。

## 按具体问题组织工作

1. **建立参数表。** 记录名称、含义、单位、中心值、信息来源、分布/范围、相关关系及类别。参数可以是 Borel 后的 `M2`、未变换的 `Q2`、任意凝聚项、质量、几何量等。先分清独立输入、由其计算的派生量和固定的模型选择。统计输入与系统平台参数只是标签，不决定程序结构。
2. **确定采样设计。** 根据用户要求选 `single` 或 `joint`。分布和协方差须有数据或明确假设；缺少的信息列明，不凭空补数。平台范围需来自本问题的稳定性依据，不能用最优点附近的任意宽度冒充平台。非矩形平台、条件相关或自定义分布可由 Agent 编写专用联合采样器，生成成对样本表传给通用程序。
3. **连接求解器。** 写薄适配器 `evaluate(parameters)`，接收任意参数字典，返回一个数、向量或 `{观测量名: 数值}`。原始质量变化时，派生的跑动质量等按模型重算；不把派生量当成额外独立抽样源。固定其他独立参数时也要固定拟合/正则化参数；若模型确实按输入重新选择某个派生参数，应在方案中明确说明。避免全局变量临时替换和函数默认参数绑定旧值。
4. **先小样本验证接线。** 检查中心点、单参数模式中其余输入是否逐行不变、联合样本是否保持相关结构、参数是否实际进入公式。若输入变化而输出不变，先区分真实不敏感与参数未传入，不能人为增大响应。用模型能够提供的反代、约束或稳定性检查检验求解结果。不要修改物理公式来迎合误差大小。
5. **执行并评估收敛。** 记录种子、抽样次数、配置、模型来源及所有失败点。根据计算成本增加样本，比较不同样本数或独立种子下的分位点和标准差；没有稳定性证据时标为试运行结果。不要静默补抽、删除失效点、裁剪输出或以零填充。
6. **报告分布及边界。** 同时报告中心点求值、样本均值/中位数、样本标准差 `sigma` 和中央 68.268949% 分位区间。按用户的“分布的一倍 sigma 区域”，优先展示中位数及该区间的上下偏差；分布近似正态时再用对称 ±sigma 表达。报告有效/无效点数、无效原因、输出协方差及所有采样假设。若有失效点，统计结果是对有效样本条件化的结果。

## Agent 可以调整的部分

参数名称、输出维数、分布、参数依赖关系、稳定区域的表示、求解器语言、样本数和计算调度均由任务决定。附带程序提供最小通用实现，不要求改写模型以迎合固定清单。可编写额外的适配器或联合采样脚本，但保留上述两种撒点语义和可复现记录。

**相关性不会因为“撒点”自动出现。** 已知相关结构应通过联合分布、协方差、共享原始参数或成对输入样本传入；不知道相关结构时如采用独立抽样，需明确写作独立假设。单参数撒点使用该参数的边缘分布，其他输入固定，不悄悄改成条件分布或相关参数一起移动。

## 附带程序

运行和配置见 [references/program.md](references/program.md)。附带 Python 参考程序仅需 NumPy。模型可以用任意语言实现；Agent 可写 Python 适配器调用现有程序，或按相同的两种抽样语义在原语言中实现。不要为了使用本 Skill 强制迁移物理程序。

```sh
python /path/to/uncertainty-analysis/scripts/run_uncertainty.py \
  --config /path/to/problem.json --mode single --parameter Q2 \
  --samples 1000 --seed 42 --output /path/to/results

python /path/to/uncertainty-analysis/scripts/run_uncertainty.py \
  --config /path/to/problem.json --mode joint \
  --samples 1000 --seed 42 --output /path/to/results
```

这里的参数名和样本数仅示意。不要把示例的参数、相关系数或区间当作实际课题输入。需要区分标准差与覆盖区间，或解释失败样本时，读取 [references/interpretation.md](references/interpretation.md)。
