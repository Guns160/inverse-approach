# 分系综撒点误差分析

本 Skill 采用师兄程序的两系综结构：**统计输入随机变化时固定系统参数；系统窗口参数随机变化时固定统计输入**。两个系综分别运行、分别报告，程序不提供总误差合成。

## 两个系综

- **`statistical`**：随机改变列入统计误差的 OPE/外部输入，(Y_1,Y_2,X_2) 等系统窗口参数保持中心值。输出分布报告均值、标准差、中位数、q16/q84 和精确中央 68.268949% 区间。
- **`systematic`**：随机改变列入系统误差的平台/窗口参数，所有统计输入保持中心值。报告包含中心值的完整包络 `central - min` 与 `max - central`，不用标准差冒充系统误差。

每个系综内部可以有多参数联合抽样、相关正态块、独立非正态参数和物理约束拒绝采样。求解失败点保留为无效样本，不补抽、不以零填充。输入候选点若违反显式约束会被拒绝，直到取得设定样本数；拒绝次数和拒绝率写入设计记录。

## 工作步骤

1. 读取具体模型和运行记录，列出所有独立输入、派生输入、固定模型选择和输出。参数可以是 Borel 后的 `M2`、未变换的 `Q2`、任意凝聚项或任意数量观测量。
2. 分别建立 `statistical` 与 `systematic` 配置。统计系综写明分布、宽度、来源和相关矩阵；系统系综写明平台范围、范围依据和随机分布。没有依据的误差和平台边界不凭空补数。
3. 写薄适配器 `evaluate(parameters)`。原始参数抽样后，由模型重算派生量；不要把派生量再当独立误差源。固定参数必须真正固定，包括正则化参数和能标，除非方案明确要求重选。
4. 先小样本验证：统计系综中系统参数逐行不变；系统系综中统计输入逐行不变；约束、相关结构和模型输出符合预期。若输入变化而输出不变，先区分真实不敏感与参数未传入。
5. 分别运行两个系综并检查样本数、失败率、分位数或包络的稳定性。不要把统计 `std` 与系统 envelope 平方相加，也不要把两个输出目录合并成一个总误差结果。
6. 报告时明确写出：中心值、样本数、种子、输入分布、相关性、约束拒绝率、无效求解样本、输出单位以及“统计/系统分离、无总误差”的约定。

## 固定量的处理

师兄参考程序中，正则化参数 `alpha` 在两个 MC 系综中都固定，不作为误差来源；能标 `mu=1.0` 也不抽样。若某个课题决定改变其中一个，必须在配置和报告中把它移入对应系综，不能让适配器无说明地重选。详见 [师兄方法记录](references/senior_method.md)。

## 运行

接口与配置格式见 [程序说明](references/program.md)。示例使用三个合成输出，仅演示结构，不含物理误差默认值。

```sh
python uncertainty-analysis/scripts/run_uncertainty.py \
  --config uncertainty-analysis/examples/toy_config.json \
  --ensemble statistical --output results

python uncertainty-analysis/scripts/run_uncertainty.py \
  --config uncertainty-analysis/examples/toy_config.json \
  --ensemble systematic --output results
```

需要解释标准差、分位区间、包络和失败样本时，读取 [统计解释](references/interpretation.md)。

本 Skill 保存在仓库顶层，不安装到本地技能目录。调用它不额外授权推送、发布或修改无关项目；结果只写入用户指定输出目录。
