# 重整化标度 $\mu$

$\mu$ 不属于抽样误差，也不属于截断误差。它是方案选择。

> **本文只记录方法。** 文中数值是当前约定，不是最终选择。

## 一、本课题的约定

**$\mu$ 固定在 2 GeV，不计入误差。**

理由：$\mu$ 是方案选择，不是测量值，没有分布可抽。项目此前预算也采用这一约定。

$\alpha_s(\mu)$ 和 $m_c(\mu)$ 由 RG 从跑动起点算到 $\mu$，随 $\mu$ 自动变化。固定 $\mu$ 意味着这两者也固定。

## 二、$\mu$ 变化时，什么跟着变

只有两个参数随 $\mu$ 跑动：

| 量 | 怎么变 | 依赖 |
|---|---|---|
| $\alpha_s(\mu)$ | 由 RG 从 $\alpha_s^{(5)}(M_Z)$ 跑到 $\mu$ | beta 函数 |
| $m_c(\mu)$ | 由 RG 从 $\overline m_c(\overline m_c)$ 跑到 $\mu$ | 质量反常量纲 |

$G_2$、$G_3$ 自身的能标依赖很小，可以忽略。

$m_c(\mu)$ 虽然只是一个参数，但它进入 OPE 的多个位置：微扰项、$G_2$ 与 $G_3$ 项的系数、微扰谱阈值、赝标量通道的留数转换。所以 $\mu$ 的实际影响会贯穿整条链，不只是改一个因子。

由此有两个后果：

**第一，扫描得到的是方案依赖的总和。** 无法把跨度拆成“$\alpha_s$ 部分”和“$m_c$ 部分”，两者由同一个 $\mu$ 驱动，天然相关。

**第二，不能与 $\overline m_c$ 的误差行相加。** $\mu$ 扫描已经包含了 $m_c(\mu)$ 的移动，若再把 $\overline m_c$ 的抽样误差并进去，同一效应会计两次。这也是本课题把 $\mu$ 固定、只让 $\overline m_c$ 参与撒点的理由之一。

## 三、与参考课题的差别

参考课题把 $\mu$ 从 1 扫到 3 GeV，中心取 2 GeV，得到 1.69 MeV（$f_\pi$）和 0.91 MeV（$f_{a_1}$）。

本课题的预算不能与那一行逐项对照。这一点在项目此前的 J/ψ 预算里已经写明。

## 四、诊断扫描

若要补一个能标诊断，用扫描，但不并入主误差。

```text
PROCEDURE mu_diagnostic(center_inputs, mu_values):
    ys ← []
    FOR each mu IN mu_values:
        y ← SOLVE(center_inputs, mu = mu)
        ys.append(y)
    RETURN (max(ys) − min(ys)) / 2
```

扫描时 $\alpha_s(\mu)$ 由 RG 自动重算，$m_c(\mu)$ 同时变化，两者不是独立的。

诊断值只用于说明能标依赖有多大，不进入平方和，也不出现在主误差表里。

## 五、报告

主误差表不列 $\mu$ 这一行。

若做了诊断，另起一段写：扫描区间、点数、得到的半宽，并注明“诊断值，未计入总误差”。
