# OPE 截断误差

OPE 只保留到有限维数。被丢掉的更高维算符对结果的影响，就是截断误差。

> **本文只记录方法。** 文中的保留阶和窗口都是示例或当前取值，实际由具体计算确定。

## 一、要估计什么

本仓库的 OPE 由微扰项、$G_2$、$G_3$ 组成，最高保留项是 $G_3$。

更高维算符没有显式包含。它们对输出的贡献，无法从现有计算里直接读出，只能用其余项的尺寸来估计。

## 二、估计方法

把最高维保留项当作所有更高维项的上界，取“含”与“不含”两次结果之差。

依据：算符维数越高，贡献被 $1/Q^2$ 的幂次压得越低。最高保留项是剩余项中最大的一项，用它做上界是保守估计。

```text
PROCEDURE ope_truncation(center_inputs):
    y_full  ← SOLVE(center_inputs, G3 = G3_center)
    y_trunc ← SOLVE(center_inputs, G3 = 0)
    RETURN |y_full − y_trunc|
```

两次计算除了 $G_3$ 之外完全一致：同样的输入、同样的窗口、同样的边界条件。

## 三、检查

1. **逐级减小。** $G_3$ 的贡献应小于 $G_2$ 的贡献。若 $G_3$ 比 $G_2$ 还大，说明窗口不在 OPE 收敛区，截断估计不可信。
2. **量级。** 截断误差不应主导总误差。若它最大，说明需要更高的 OPE 阶数，或窗口选择有问题。
3. **符号。** 平方和里取绝对值，但报告里可以给出带符号的响应方向，便于判断系统偏向。
4. **边界一致。** 两次计算的 $s=\Lambda$ 边界条件必须用同样的规则。若一边用完整 OPE、一边用截断 OPE，差值会混进边界项。

## 四、与撒点的区别

| 项目 | 高斯撒点 | OPE 截断 |
|---|---|---|
| 有没有分布 | 有 | 没有 |
| 端点个数 | 由样本数决定 | 只有两个 |
| 是否进系综 | 是 | 否，单独一个数 |
| 合成方式 | 先算标准差或极差，再平方和 | 直接平方和 |

不存在“$G_3$ 取一半”这种中间值。$G_3$ 要么在，要么不在。

这一项没有随机数，也不能报标准差或分位数。表里只写一个数。
