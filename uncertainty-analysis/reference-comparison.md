# 与参考课题的差异

参考课题是 $\pi$ 与 $a_1(1260)$ 的轴矢流通道，本课题是粲偶素。两者的输入清单只部分重叠。

## 一、逐项对照

| 参考课题（$\pi$） | 本课题（粲偶素） | 差异 |
|---|---|---|
| $m_u\langle\bar uu\rangle+m_d\langle\bar dd\rangle$ | 无 | 轻夸克凝聚，粲偶素 OPE 不出现 |
| $\langle\alpha_sGG\rangle$ | $G_2$ | 同名，取值不同（0.07 vs 0.038） |
| $\sum_{q}m_q\langle g_s\bar q\sigma TGq\rangle$（dim-5） | 无 | 混合凝聚，粲偶素 OPE 不含 |
| $\langle g_s\bar qq\rangle^2$、$\langle g_s^2\bar qq\rangle^2$ | 无 | 四夸克凝聚，粲偶素保留的是三胶子项 |
| $\kappa\equiv\langle\bar ss\rangle/\langle\bar qq\rangle$ | 无 | 无奇异夸克输入 |
| $M_{a_1}$、$\Gamma_{a_1}$ | `MASSES`（极点质量） | 参考课题把共振参数当先验输入，带实验误差；本课题极点质量是模型固定量 |
| $\mu$ 扫描 $[1,3]$ GeV | $\mu$ 固定 | 处理不同 |
| OPE 截断（dim-6 四夸克） | OPE 截断（$G_3$） | 形式相同，截掉的对象不同 |
| 无 | $\bar m_c(\bar m_c)$ | **本课题独有**，重夸克跑动起点 |
| 无 | $a_1$（轴反常） | 仅赝标量通道 |
| $G_3=8.2\,G_2$（导出量） | $G_3$ 独立常数 | 参考课题三胶子凝聚由 $G_2$ 导出，不独立；本课题独立 |

## 二、三点结论

**第一，本课题多出重夸克质量输入。**

$\bar m_c$ 在参考课题里没有对应物。参考课题的轻夸克质量组合误差只有 0.002 MeV，可以忽略；本课题的 $\bar m_c$ 通过 RG 同时改变 $m_c(\mu)$ 和微扰谱，是最主要的输入来源。

$\alpha_s$ 在本课题取已跑动到计算能标的值，不单独赋误差，与参考课题的处理一致。

**第二，本课题少掉全部轻夸克凝聚。**

参考课题里十个输入误差行，有五行是轻夸克或四夸克凝聚，本课题一行都没有。粲偶素的 OPE 只保留胶子型算符。

**第三，$G_3$ 的独立性需要确认。**

参考课题用真空饱和把三胶子凝聚写成 $G_3=8.2\,G_2$，因此 $G_2$ 的误差自动覆盖 $G_3$。本课题把两者都写成独立常数。

若沿用同样的真空饱和关系，$G_3$ 不应单独作为误差源，否则会重复计入。这一点需要先确定，再决定 $G_3$ 是独立输入还是 $G_2$ 的导出量。
