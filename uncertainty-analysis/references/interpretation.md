# 统计解释与适用边界

## 统计系综的分布宽度

同时保留两个量，避免把偏斜分布强行压成对称误差：

- `std`：有效输出样本标准差，分母为有效样本数减一。
- 中央 68.268949% 覆盖区间：分位点 0.158655254 与 0.841344746。

`q16` 与 `q84` 是师兄摘要中使用的近似分位标签；精确 68% 端点另存在 `central_68_interval`。高斯分布下，中央区间对应均值 ± 标准差；偏斜、多峰或重尾分布中二者通常不同。中心参数处的模型结果单独列出，它不一定等于样本均值或中位数，也不一定落在区间内。

## 系统系综的包络

系统系综报告包含中心值在内的最小值与最大值：

```text
envelope_minus = central - min(central, samples)
envelope_plus  = max(central, samples) - central
```

这对应师兄程序的平台散点包络。它通常比 68% 区间更保守，也不等于标准差。系统包络与统计 `std` 不是同类量，不能平方相加，本工具不生成总不确定度。

## 两个系综

统计系综回答：固定系统窗口时，统计输入的联合分布如何传播到输出分布。系统系综回答：固定统计输入时，平台/窗口参数随机变化的完整结果范围如何。

统计系综内部的正态块用协方差指定；剩余参数可显式声明独立并使用其它边缘分布。系统系综通常使用有限范围上的均匀散点。非正态边缘一般不能仅靠协方差矩阵唯一确定联合分布；可由上层生成成对样本表，例如从已拟合后验抽样、相关实验数据重采样或明确条件模型。不得自动假设未声明的 copula。

如果两个派生量共享同一原始参数，先抽原始参数再一起计算派生量。不要把原始参数误差和已由它传播得到的派生量误差重复计入。正则化参数、能标或其它模型选择若未列入本系综，报告必须称其为固定，不应暗示其误差已传播。

## 约束与失败点

区分两种无效：

- **输入候选点违反声明式物理约束**：在抽样阶段被拒绝，直到达到设定样本数；拒绝次数与拒绝率写入设计记录。由此得到的是条件化输入分布。
- **模型求解失败**：该点保留为无效输出行，不补抽、不以零填充。默认统计只使用所有观测量均有效的完整配对行，并显式标注条件化。

正式结果需检查样本量、种子稳定性和失败率。可比较 N 与 2N 的统计量或包络端点，并结合多种子重复报告 Monte Carlo 数值误差。少量演示样本只证明程序接线，不证明物理结果收敛。

## 方法依据

JCGM 101:2008（BIPM，《Evaluation of measurement data — Supplement 1: Propagation of distributions using a Monte Carlo method》）5.1、5.3、7.3–7.7 区分输入联合分布、输出标准差及覆盖区间。本 Skill 采用师兄程序的两系综应用方式：统计误差看输出分布，系统误差看平台散点包络；不把规范例子作为物理参数或平台默认值。
