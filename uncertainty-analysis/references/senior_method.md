# 师兄 `TPsDC_IP_v15_1error.m` 的误差方法记录

参考文件：`TPsDC_IP_v15_1error.m`（2026-10-15 提供）。本记录只总结方法，不把其中数值设为通用默认值。

## 总体结构

程序严格分成两个 Monte Carlo 系综：

1. **statistical**：随机改变 OPE/外部输入，固定 `Y1`、`Y2`、`X2`。
2. **systematic**：随机改变 `Y1`、`Y2`、`X2`，固定所有 OPE/外部输入和 `Pi0_F`。

二者分别运行、分别保存和打印，没有任何总误差合成。

## 统计系综

默认 500 个样本、种子 15001。当前配置：

- `qq_root` 高斯撒点，宽度 0.02，再按 `qq = -qq_root^3` 重构。
- `gg` 高斯宽度 0.006。
- `LambdaBar` 高斯宽度 0.05。
- `m0` 独立均匀分布在 `[0.6, 1.0]`。
- `ass` 与 `Pi0_F` 当前宽度为 0，实际固定。
- 六个采样坐标的相关矩阵当前是单位阵。
- 每次样本重构 `qgq = m0 * qq`。

候选点必须全部为正，且 `LambdaBar < X2 - hx`。违反者被拒绝，继续抽取直到取满 500 个物理有效输入。因此实际传播的是这些约束下的条件分布。

## 系统系综

默认 500 个样本、种子 15002。所有统计输入固定，联合均匀随机抽取：

```text
Y1 in [2, 4]
Y2 in [10, 15]
X2 in [2, 3]
```

要求 `Y2 > Y1`、满足最小 Borel 宽度，且 `X2 > LambdaBar + hx`。这是散点抽样，不是三维 Cartesian 网格。

## 输出与报告

每个样本重新构造 (x,y) 网格、OPE 输入和反问题算子，然后求解。H、S 通道每次重算；F 通道默认不重算，`Pi0_F=0.167` 作为外部固定值。输出包括：

```text
lambda_H^2 = Pi0_H / Pi0_F
delta_HE^2 = Pi0_S / Pi0_F
lambda_E^2 = lambda_H^2 - delta_HE^2
```

统计系综打印 median、q16、q84 和 std；图形另画 68.27% 与 95.45% 分位区间。系统系综打印包含中心值的完整包络，而不是标准差或 68% 区间。无效求解样本计入 failure rate，不从样本集中删除。

## alpha 与 mu 的处理

- **`alpha` 不做误差撒点。** 中心诊断可以按 quasi-optimality 选 `Lcc`，但开启任一 MC 后程序强制 `alpha_selection_mode='fixed'`。三个通道各自固定 `Lcc_F=134`、`Lcc_H=107`、`Lcc_S=107`，并按 `alpha=1e-2*sqrt(0.8)^Lcc` 得到固定值。
- **`mu` 不做误差撒点。** `par.mu=1.0` 固定，且不在统计参数表 `ass, qq_root, gg, m0, LambdaBar, Pi0_F` 中。也就是说，当前程序没有能标不确定度行。

本仓库当前粲偶素工作约定使用 `mu=2.0`；师兄三粒子示例中的 `1.0` 不作为本项目默认。

如果我们的某个课题要估计正则化或能标误差，必须显式把它列入统计或系统系综，或另立第三个诊断系综；不能沿用当前师兄程序时无说明地把它混入其它参数。
